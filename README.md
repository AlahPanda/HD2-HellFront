# HD2 — HellFront

**A curated Helldivers 2 modpack focused on immersive warfare, enhanced audio, custom models, and cinematic visuals.**

HellFront brings together carefully selected community-made mods to create a more intense and atmospheric Helldivers 2 experience while preserving the work and recognition of the original creators.

## Available Editions

### HellFront | EAC Compatible

Designed for the official version of Helldivers 2, featuring enhanced weapon sounds, explosions, voice lines, custom models, textures, and visual improvements.

**Disclaimer:** The name "EAC Compatible" does not guarantee protection against bans. Mods are not officially supported by Arrowhead, and users install them at their own risk.

### HellFront | Reforged

An expanded edition designed for HellForge, combining the base HellFront experience with additional modifications and features.

## Installation

HellFront uses Arsenal Mod Manager to manage mods and preserve selected configurations.

Installation instructions and downloadable profiles will be available with the first release.
